# Atelier Patel brand assets

Logos and marks for [Atelier Patel](https://atelierpatel.com), a software studio in Lausanne. This
repository is public so the files can be linked directly (for example from Microsoft 365 or Outlook,
which want a logo at an HTTPS address).

Link to a file with its raw URL:

```
https://raw.githubusercontent.com/ihsur7/atelierpatel-brand/main/<path>
```

## Which file to use

| Use | File |
|---|---|
| Microsoft 365 / Outlook org theme logo (fits 200 × 30), on a dark bar | `png/lockup-horizontal-paper-200w.png` |
| The same, on a light bar | `png/lockup-horizontal-ink-200w.png` |
| Square logo or profile picture | `png/avatar-glyph-glow-240.png` (also 96, 512, 1024) |
| Square logo, plain | `png/glyph-square-ink-512.png` or `png/glyph-square-paper-512.png` |
| BIMI-style square SVG (SVG Tiny PS) | `svg/glyph-square-bimi.svg` |
| Vector logos | `svg/` |

## Contents

- `svg/` — the glyph, the horizontal and stacked lockups and the wordmark, in ink (`#0b0b0b`, for
  light backgrounds) and paper (`#f4f3f0`, for dark ones); `svg/shapes/` holds the seven brand shapes.
- `png/` — the same marks as PNGs: transparent glyphs and lockups, solid square glyphs, and the
  avatar (the glyph on the brand glow).
- `social/` — the link-preview image.
